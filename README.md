# GoWay Car Rental Website 🚗

## 📖 Introduction

The **GoWay Car Rental Website** is a responsive and user-friendly platform designed for seamless car rental booking.  
The project aims to **digitize and simplify** the car rental process by providing an online system where users can:

- Search for cars
- View details and specifications
- Filter cars based on preferences
- Book cars securely

This project is developed as part of a **Final Year College Project**, showcasing modern web technologies and software engineering practices.

---

## 🎯 Objectives

- To provide an easy-to-use platform for renting cars online
- To allow users to search, filter, and view car details conveniently
- To implement a booking system with cart and checkout functionality
- To ensure responsiveness across devices (desktop, tablet, mobile)
- To demonstrate modern frontend development using **React.js, Tailwind CSS, and Framer Motion**

---

## 🛠️ Technologies Used

### Frontend

- **React.js** – Component-based UI development
- **Vite** – Fast development and build tool
- **Tailwind CSS** – Utility-first responsive styling
- **Framer Motion** – Smooth animations and transitions
- **React Router DOM** – Page navigation and routing

### Backend (Optional Integration)

- **Express.js** – For authentication and data handling
- **MongoDB** – For storing car data, users, and bookings

### Deployment

- **Vercel** – For hosting and deployment

## ⚙️ Installation & Setup

To run this project locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/yourusername/goway-car-rental.git
   cd goway-car-rental
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Start development server**

   ```bash
   npm run dev
   ```

4. **Build project for production**
   ```bash
   npm run build
   ```

## 📑 Features Implemented

- **Home Page** with a search form and featured cars
- **Car Listings Page** with filtering and sorting options
- **Car Details Page** showing full specifications and rental price
- **Booking Cart System** where users can add and remove cars
- **Checkout Page** to confirm rental bookings
- **Login/Signup System** for authentication (Firebase / Node.js)
- **My Bookings Page** to manage past and active bookings
- **Fully Responsive Design** adaptable to all devices
